# 台股小鎮 stock-town

把台股每日收盤資料變成一座 3D 迷你小鎮。每檔股票或 ETF 都是一間店，成交越熱絡，街上的人潮與車流就越多。

## 看點

- **店面排序**：依當日成交金額排名
- **人潮與車流**：成交金額越大，路人和車子越多
- **門口兩條隊伍**：右邊紅繩是三大法人買進、左邊綠繩是賣出，長度依金額換算
- **進店頻率**：成交筆數越多，叫號越快
- **看板與資訊卡**：收盤價、漲跌、成交量、近 30 日走勢，紅漲綠跌
- **播放控制**：暫停，或切換 1×／10×／30×／60× 倍速

目前收錄：台積電（2330）、聯發科（2454）、元大台灣50（0050）、元大台灣50反1（00632R）。

## 資料

- 來源：[臺灣證券交易所]公開資料
- 更新：每個交易日台灣時間 17:30
- 每天只發出少量請求，不做即時抓取
